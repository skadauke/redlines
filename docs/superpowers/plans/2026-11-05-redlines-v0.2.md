# Redlines v0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the v0.1 proof of concept into a very basic Mac editor: formatting, find, a file sidebar and Preferences, good rendering, and @Claude and @Codex answering in comment threads and making tracked edits, ending with a signed v0.2.0 that runs the demo twice in a row.

**Architecture:** `@redlines/format` gains `fmt` marks. `@redlines/editor` gains a command registry, and new plugins (`formatting`, `find`, `code`, `agents`, `agent-claude`, `agent-codex`) register through it. In a run started in the app, the agent CLI talks MCP to a native `redlines` program, which pipes it over a private socket to tools running in the webview against the live editor, so the app stays the only writer. The same native program, Rust with QuickJS and the bundled TypeScript, is the command line for agents outside the app, with no Node.

**Tech Stack:** TypeScript (strict), CodeMirror 6, Vite (rolldown), Vitest (+ happy-dom), Tauri v2 (Rust, objc2 on the Mac), rquickjs, the `ignore` crate, `@codemirror/language-data`.

**Spec:** [docs/superpowers/specs/2026-11-04-v0.2-design.md](../specs/2026-11-04-v0.2-design.md), with [docs/format.md](../../format.md) as the source of truth for `packages/format`. Read the spec's section named in each task.

## Global Constraints

- Node >=22 and pnpm 10.28.0. On this Mac, run pnpm as `npx -y pnpm@10.28.0`, git as `/usr/bin/git`, and prefix cargo and tauri commands with `PATH=/opt/homebrew/opt/rustup/bin:$PATH`. The shell is zsh: quote globs, and use Python or `git grep` rather than `--include=*.ts`.
- TypeScript as in `tsconfig.base.json`: strict, `noUncheckedIndexedAccess`, `verbatimModuleSyntax`, `erasableSyntaxOnly`. Workspace packages export their `.ts` sources. Prettier: width 100, single quotes.
- Tests are `src/**/*.test.ts` beside the code; `// @vitest-environment happy-dom` for a DOM; `*.node.test.ts` for Node types in `apps/desktop`. Test CodeMirror through state and decoration sets, not layout.
- Every PR passes `npx -y pnpm@10.28.0 typecheck && npx -y pnpm@10.28.0 lint && npx -y pnpm@10.28.0 test && npx -y pnpm@10.28.0 format:check`. PRs touching Rust also pass `cargo clippy --all-targets -- -D warnings` and `cargo test` in the crate they touch.
- `docs/format.md` decides format behavior. Where it is silent, extend it deliberately in the same PR. No marker starts a line, reject restores the exact bytes, and opening and saving without editing leaves a file byte for byte the same.
- **What the document shows is in the file.** The one exception is a run's live line (status, first-run question, failure), which is never written and doesn't survive closing the document.
- Nothing in `packages/` or `plugins/` imports `@tauri-apps`. Anything host-specific arrives through a `Host` capability.
- Redlines never reads, stores or passes Claude or ChatGPT credentials. It runs the agents' own programs, and their own status commands for sign-in state.
- Agent limits: reply 200 characters with no blank line, details 2,000, status 40, note 200.
- Agent handles: `claude-<you>`, `codex-<you>`, name "Claude" or "Codex", `agent: true`, `for: <you>`. The UI says "Claude"; "Claude Code" may appear only in plain text saying the app runs it, never in a feature's name.
- Look: almost no chrome, quiet grays, thin rules. Color means a person; red is the pen and the first author. No number badges, no toolbar, no status bar. Title-bar icons have no labels. Failures are one line, never a dialog. News that must not interrupt goes in a notification (`apps/desktop/src/ui/notifications.ts`).
- Document fonts are only the bundled Carlito, Gelasio and Cousine.
- Never mention any other Markdown editor as a style or design reference in code, comments, docs, commits, PRs or issues.
- Commit messages follow the repo's "Area: what changed" form and end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; PR bodies end with the generated-with line. Merge when no critical issue is open; file follow-ups as issues. `gh pr merge --delete-branch` fails on a branch a worktree holds, so delete the remote branch with `git push origin --delete` afterwards.

## Review Focus

1. **Someone else's words starting a run.** A comment naming @Claude that arrives by reload, paste, undo, git or a colleague's save must start nothing. Only the act of posting in this app's box does. Test: Task 27.
2. **Typing while an agent edits.** With unsaved edits and an agent's `str_replace` landing, both survive, the caret stays, the file isn't written, and ⌘S saves both. With no unsaved edits, each agent edit is on disk as it lands. Test: Task 27.
3. **The document changing under a run.** A sidebar click, File ▸ Open, a window closing or the app quitting during a run must never put the next edit in another file. Test: Task 27.
4. **Agent programs misbehaving.** Missing, signed out, killed, printing garbage or unknown events, never finishing, or ending without calling `reply`: one line, no dialog, nothing lost, and the log says what happened. Test: Tasks 26 and 27.
5. **Formatting across other people's marks and odd bytes.** Bold across someone's insertion, a selection crossing paragraphs, CRLF files and emoji: never an illegal marker, and reject restores the exact bytes. Test: Task 5, using `random-docs.ts`.

  title: string;

  /** Where a host with menus shows it. */

  group?: string;
  /** Returns false when it did nothing. */

  isEnabled?(state: EditorState): boolean;
