# Redlines v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A demo-ready macOS app that opens a Markdown file, shows it as a finished document, shows and records tracked changes and comments stored in the file, lets you accept and reject them, and lets Claude Code suggest tracked edits through a `redlines` command.

**Architecture:** `@redlines/format` reads and writes the format (marks, ledger, views, decisions, tracked edits) as pure functions over the file's text. `@redlines/editor` is CodeMirror 6 over that same text, hiding syntax and markers with decorations. `@redlines/themes` holds the theme tokens and bundled fonts, `@redlines/review` the margin notes, cards and review bar, `redlines` (packages/cli) the command line, and `apps/desktop` the Tauri shell: title bar, menus, files.

**Tech Stack:** TypeScript (strict), CodeMirror 6, Vite, Vitest (+ happy-dom), Tauri v2 (Rust), `yaml`, `@fontsource/{carlito,gelasio,cousine}`.

**Spec:** [docs/design.md](../../design.md) (product, look, controls) and [docs/format.md](../../format.md) (file format; the source of truth for `packages/format`).

## Global Constraints

- Node >=22 and pnpm 10.28.0. This machine has pnpm 9, so run pnpm as `npx -y pnpm@10.28.0`. Rust lives in `/opt/homebrew/opt/rustup/bin`; prefix cargo and tauri commands with `PATH=/opt/homebrew/opt/rustup/bin:$PATH`.
- TypeScript as in `tsconfig.base.json`: strict, `noUncheckedIndexedAccess`, `verbatimModuleSyntax` (`import type` for types), `erasableSyntaxOnly` (no enums, namespaces or parameter properties). Workspace packages export their `.ts` sources.
- Prettier: print width 100, single quotes. Run `npx -y pnpm@10.28.0 format` before committing.
- Tests are `src/**/*.test.ts` next to the code. A test needing a DOM starts with `// @vitest-environment happy-dom`. Test CodeMirror through state and decoration sets, not layout measurement.
- Every PR passes `npx -y pnpm@10.28.0 typecheck && npx -y pnpm@10.28.0 lint && npx -y pnpm@10.28.0 test && npx -y pnpm@10.28.0 format:check`. PRs touching `apps/desktop/src-tauri` also pass `cargo clippy --all-targets -- -D warnings` there.
- `docs/format.md` decides format behavior. If the code needs behavior the spec doesn't state, change the spec in the same PR.
- v0.1 format subset: read every kind; render and decide `ins`, `del`, `sub`, `cmt` (range and point) and `hl`. `fmt`, `split`, row and column marks, moves and history blocks are parsed and kept byte for byte, with markers hidden, but have no special rendering or decisions (`accept`/`reject` throws `EditError('not supported in v0.1')`).
- Document fonts are only the bundled Carlito, Gelasio and Cousine, never system fonts. Interface text uses the theme's interface font.
- Color means a person. Text and controls are grays; red (`--rl-red`) is only the Track Changes pen. No number badges. Title-bar icons have no labels; hover shows a hint or opens the menu.
- Never mention any other Markdown editor as a style or design reference in code, comments, docs, commits or PRs.
- Opening and saving a file without editing it leaves it byte for byte the same (format §9.2).

## Review Focus

1. **Plain files and untouched saves.** A file without marks or ledger, or with CRLF line endings, must round-trip byte for byte through `parse`, the editor (`createEditor` → `getDoc`) and save. Tests: Task A1 (`parse` keeps `text` identical), Task B2 (CRLF round trip).
2. **Broken markup.** An unclosed marker, a closer without an opener, a mark without a ledger entry, or a ledger that isn't valid YAML must never stop a file from opening: report a warning and treat the markup as text. Tests: Task A1.
3. **Typing next to hidden markers.** With Track Changes on, typing at the end of your own insertion extends it, typing inside someone else's insertion splits it, Backspace and Delete act on visible text and never on a marker, and Undo restores the exact previous text. Tests: Task E2.
4. **The file changes on disk while open** (Claude edits it through the command line). With no unsaved edits, the app reloads it; with unsaved edits, it keeps them and shows a notice, never overwriting either side. Tests: Task C2.
5. **Text with emoji, combining characters and CRLF in payloads and comments.** Offsets are UTF-16 code units throughout (as CodeMirror uses), and payloads round-trip through `encodePayload`/`decodePayload`. Tests: Task A1 (emoji before a mark), Task D2 (deleting emoji text).

`packages/format/src/types.ts` adds:

```ts
/** A change to a string, in UTF-16 offsets of the string before the change. Lists are sorted and don't overlap. */
export interface TextChange { from: number; to: number; insert: string }
export interface Range { from: number; to: number }
/** One stretch of a mark. `content` lies between the markers; a mark without a closer has an empty content at `open.to`. */
export interface Segment { open: Range; content: Range; close?: Range }
export interface MarkRange {
  id: string;
  kind: MarkKind;
  /** The decoded payload: old text for `del` and `sub`, operations for `fmt`, `row`/`col` for table marks. */
  payload?: string;
  segments: Segment[];
  /** From the ledger; `{ by: 'unknown', at: '' }` when the entry is missing. */
  entry: MarkEntry;
}
export type WarningCode =
  | 'unknown-key' | 'duplicate-id' | 'line-start-marker' | 'kind-mismatch' | 'missing-entry'
  | 'orphan-entry' | 'orphan-thread' | 'unclosed-mark' | 'unopened-close' | 'bad-ledger';
export interface Warning { code: WarningCode; message: string; id?: string; range?: Range }
export interface Parsed {
  /** The input, unchanged. */
  text: string;
  /** Marks in document order of their first segment. */
  marks: MarkRange[];
  ledger: Ledger;
  /** The ledger comment plus the blank line before it; null when the file has none. */
  ledgerRange: Range | null;
  warnings: Warning[];
}
export interface PositionMap {
  /** A view offset to a source offset. `assoc` picks the side of a hidden marker: -1 before, 1 after. */
  toSource(pos: number, assoc?: -1 | 1): number;
  /** A source offset to a view offset; offsets inside hidden text map to the nearest visible one. */
  fromSource(pos: number): number;
}
export interface DocView { text: string; map: PositionMap }
export interface EditContext {
  /** The author, added to the ledger's people when missing. */
  author: Person;
  time: Time;
  /** For ids; tests pass a deterministic source. */
  random?: (n: number) => Uint8Array;
  note?: string;
  group?: string;
}
```

### Task B2: live preview

**Files:** Create `packages/editor/src/preview/decorations.ts`, `packages/editor/src/preview/table.ts`, `packages/editor/src/preview/theme.ts`, `packages/editor/src/preview/preview.test.ts`. Modify `packages/editor/src/index.ts`.

Decisions:
- Line classes per block: `rl-h1` … `rl-h6`, `rl-quote`, `rl-li`, `rl-codeblock`, `rl-hr`. Inline classes: `rl-strong`, `rl-em`, `rl-code`, `rl-link`, `rl-strike`.

- Tables: while the selection is outside a table, a block replace decoration shows a rendered `<table>` widget (header row, horizontal rules only, cells with inline Markdown). Clicking it puts the caret in the table, which shows the source lines with `|` and the delimiter row in `--rl-syntax`.
- Base theme: everything through the Task 0 tokens. Centered column (`max-width: var(--rl-column)`), page background, `--rl-ink` text, caret `var(--rl-caret, var(--rl-author-1))`, headings with no rule under them, code in `--rl-font-mono` on `--rl-tint`, blockquote with a 2px `--rl-rule` bar.
